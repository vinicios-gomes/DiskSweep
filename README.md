# DiskSweep

<img src="Resources/AppIcon-1024.png" width="128" align="right" alt="DiskSweep icon">

A native macOS app (SwiftUI + Swift Package Manager) that shows how full your disk is and helps you
reclaim space: developer caches, Docker images, iOS simulators, `node_modules`, logs and more.
Every item can be opened and drilled into, so you choose exactly what to delete.

🇧🇷 [Leia em português](README.pt-BR.md)

> ⚠️ **DiskSweep deletes files.** Nothing is removed without an explicit confirmation, and every item
> shows what will be affected first. Still, review each list before confirming and keep backups of anything
> you care about. Provided "as is", without warranty (see [LICENSE](LICENSE)).

## Features
- Live free-space indicator, usage history chart and a menu-bar item.
- 25+ cleaners: npm/Yarn/pnpm/pip/Gradle/CocoaPods caches, Xcode DerivedData, iOS simulators, Docker, Homebrew,
  browser caches, logs, Trash, Downloads, `node_modules` discovery, and an explorer for large folders.
- **Drill-down**: open any item, navigate subfolders, tick individual entries and delete only those.
- Native confirmation dialog and a progress overlay while deleting.
- Also usable from the terminal (`scripts/clean-cli.sh`).

## Requirements
macOS 14+ and Swift 5.10+ (Xcode or Command Line Tools). Some locations (e.g. `~/Library/Containers`) may need
**Full Disk Access** for the app: System Settings → Privacy & Security → Full Disk Access.

## Build & run
```bash
git clone https://github.com/vinicios-gomes/DiskSweep.git
cd DiskSweep
./scripts/run-app.sh      # builds build/DiskSweep.app and opens it
./scripts/build-app.sh    # build only
./scripts/clean-cli.sh    # terminal menu
swift build && swift test # plain SwiftPM (needs a complete Swift toolchain / Xcode)
```
`open Package.swift` opens the project in Xcode.

> `build-app.sh` falls back to `swiftc` when the installed SwiftPM cannot link its manifest
> (seen with some Command Line Tools installs).

## Install
**Homebrew (recommended)**
```bash
brew tap vinicios-gomes/disksweep
brew trust --cask vinicios-gomes/disksweep/disksweep   # Homebrew 7+ requires trusting third-party casks
brew install --cask disksweep
```
Upgrade with `brew upgrade --cask disksweep`, remove with `brew uninstall --cask --zap disksweep`.

**Manual:** download the `.dmg` from [Releases](https://github.com/vinicios-gomes/DiskSweep/releases) and drag the app to Applications.
DiskSweep is ad-hoc signed and **not notarized**, so macOS blocks the first launch ("Apple could not verify…").
Open System Settings → Privacy & Security → **Open Anyway**, or run
`xattr -dr com.apple.quarantine /Applications/DiskSweep.app`. The Homebrew cask does this for you.

## Adding a cleaner
Create an executable `shell/cleaners/NN-name.sh`:
```bash
#!/bin/bash
source "$(dirname "$0")/../lib/strategy_path.sh"
CLEANER_NAME="Yarn cache"
CLEANER_TARGETS=("$HOME/Library/Caches/Yarn")
cleaner_dispatch "$@"
```
The app and the terminal menu pick it up automatically. See [Docs/ARCHITECTURE.md](Docs/ARCHITECTURE.md)
and [CONTRIBUTING.md](CONTRIBUTING.md).

## Safety model
- Deletion is limited to `$HOME` and never removes the home folder itself.
- Each path is validated against the cleaner's scope (real path); id-based items only accept ids from the current listing.
- The UI always asks for confirmation; scripts expose a read-only `plan` command separate from `apply`.
